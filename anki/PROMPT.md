# Prompt для создания Anki карточек из английского текста

## Инструкция

Используй этот prompt, когда нужно создать Anki карточки из нового текста.

---

## Prompt

```
Вот английский текст:

[ВСТАВЬ ТЕКСТ СЮДА]

Проанализируй текст и извлеки из него:
1. Фразовые глаголы (phrasal verbs)
2. Идиомы
3. Устойчивые выражения
4. Сложные грамматические конструкции

Критерии отбора:
- Уровень B1-C1 (НЕ включай базовые фразы уровня A1-A2)
- Фразы должны быть полезны для изучения
- Исключи очевидные и простые конструкции

Для каждой фразы создай кортеж в формате:
("фраза", "контекст из текста", "перевод на русский")

Результат запиши в файл `02_Hobbies/English/phrases_data.py` в формате:

```python
PHRASES = [
    ("фраза 1", "контекст 1", "перевод 1"),
    ("фраза 2", "контекст 2", "перевод 2"),
    # ...
]
```

После этого запусти:
```bash
python3 02_Hobbies/English/anki_phrases_generator.py
```

Это создаст файл `anki_phrases.csv` готовый для импорта в Anki.
```

---

## Пример использования

1. Копируешь английский текст
2. Вставляешь в prompt выше вместо `[ВСТАВЬ ТЕКСТ СЮДА]`
3. Отправляешь AI
4. AI создает `phrases_data.py` с отобранными фразами
5. Запускаешь `anki_phrases_generator.py`
6. Импортируешь `anki_phrases.csv` в Anki

## Настройки импорта в Anki

- **Разделитель:** Semicolon (`;`)
- **Поля:**
  - Field 1 → Front (фраза + контекст в HTML)
  - Field 2 → Back (перевод в HTML)
- **Тип карточки:** Basic (и reverse если нужно)

### HTML-форматирование

Карточки автоматически форматируются с HTML (цвета для темной темы):

**Front (лицевая сторона):**
- Фраза: жирный шрифт, светлый цвет (#e8e8e8)
- Контекст: курсив, серый цвет (#a0a0a0)
- Размер шрифта: 18px для фразы, 16px для контекста

**Back (обратная сторона):**
- Перевод: обычный шрифт, светлый (#d0d0d0)
- Размер шрифта: 17px

Цвета оптимизированы для темной темы Anki. Anki автоматически распознает HTML в полях.

## Озвучка (опционально)

Для генерации карточек с озвучкой:

1. Установи библиотеку:
   ```bash
   pip install gtts
   ```

2. Используй скрипт с озвучкой:
   ```bash
   python3 anki_phrases_generator_with_audio.py
   ```

3. Скопируй папку `audio/` в Anki media folder:
   - **Linux:** `~/.local/share/Anki2/User 1/collection.media/`
   - **Windows:** `%APPDATA%/Anki2/User 1/collection.media/`
   - **Mac:** `~/Library/Application Support/Anki2/User 1/collection.media/`

4. Импортируй CSV как обычно

Аудио будет автоматически воспроизводиться при показе карточки.

## Советы

1. **Качество важнее количества** — лучше 30 хороших фраз, чем 100 посредственных
2. **Контекст должен быть коротким** — до 100 символов
3. **Перевод должен быть точным** — не дословным, а смысловым
4. **Группируй по типам** — сначала фразовые глаголы, потом устойчивые выражения
5. **Озвучка полезна для произношения** — используй для сложных фраз
