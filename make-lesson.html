How to make a lesson

Paste the prompt into Cursor / ChatGPT. Fill the Topic block at the bottom. The spec URLs are filled from this site so the model can open them.

Before you paste

  1. Work in this repo (so the model can read html/ and specs/).
  2. Copy the prompt. Replace [TOPIC] / [LEVEL] / notes.
  3. Canonical files: health.html (vocab), perfect-have-had.html (grammar), synonyms.html (many groups).
  4. Full rules: HTML_LESSON_SPEC.md · drills: HTML_LESSON_TEMPLATES.md · short overview: teacher.html.
