Как собрать HTML-урок

Один файл = один урок. HTML + CSS + JS внутри. Без CDN, открывается как страница на GitHub Pages.

Репозиторий

lessons/Исходные markdown-конспекты (лексика, handout)

Жёсткие запреты

  • Не мешать темы. Одна форма / один паттерн / один набор слов.
  • Никаких тестов с вариантами (radio, A/B/C, клик по готовой фразе как ответ).
  • Упражнение = ученик сам пишет в input / textarea.
  • Словарные блоки и задания всегда shuffle (Fisher–Yates) при загрузке и по «ещё раз».

Язык интерфейса

English: кнопки, навигация, названия разделов, бейджи Type · Gap / Match, счётчики.

Русский: повествовательная теория, переводы, «почему так».

Жанр главы

Не шпаргалка и не «3 примера + формула + квиз». Сначала происхождение и смысл, потом формула. Эталон длины — Present Perfect.

  1. Kicker + заголовок — что учим одной строкой
  2. Происхождение формы
  3. Смысл (камера говорящего)
  4. Формула — следствие, не наоборот
  5. Одно сквозное предложение / карточки слов
  6. Граница / ловушки
  7. Письмо (Gap, Match, Dictation…)
  8. Cheat sheet внизу

Порядок работы

  1. Прочитать handout в lessons/, выписать секции.
  2. Скопировать эталон из html/.
  3. Заменить KEY_BASE (уникально на урок), title, nav, теорию, VOCAB_BLOCKS / DRILL_SECTIONS / MATCH_SETS.
  4. data-drill / data-match должны совпадать с ключами в объектах.
  5. EN в UI, RU в теории, Check с классом btn, поток сверху вниз.
  6. Добавить карточку на index.html.

Полные документы

На GitHub markdown рендерится. С Pages .md может открыться как сырой текст — это нормально, источник правды тот же.

  • specs/HTML_LESSON_SPEC.md — стиль, запреты, проверка букв, shuffle
  • specs/HTML_LESSON_TEMPLATES.md — каркас секции, CSS заданий, форматы данных
  • lessons/health.md · synonyms.md · medical.md (конспект без HTML)
