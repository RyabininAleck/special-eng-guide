How to build an HTML lesson

One file = one lesson. HTML + CSS + JS in a single document. No CDN. Opens on GitHub Pages.

Student-facing UI is English. Narrative theory and glosses may stay Russian.

Hard rules

  • One topic per lesson (one tense, one pattern, one word set). Neighbouring forms: grey, marked “not this chapter”.
  • No multiple-choice. No radio, A/B/C, or clicking a ready-made phrase as the answer.
  • The student types in input / textarea.
  • Vocab and drills always shuffle (Fisher–Yates) on load and on Shuffle. Source-array order is never screen order.

UI language

English: buttons, nav, section titles, Type · Gap / Match badges, counters.

Russian: narrative theory, glosses, “why” notes when English would block the student. Input is always English.

Genre: textbook chapter, not a cheat sheet

Not “3 examples + formula + quiz”. Origin and meaning first, formula second. Length bar: Present Perfect.

  1. Kicker + title — one line on what we teach
  2. Origin of the form
  3. Meaning (speaker’s camera)
  4. Formula — consequence, not the start
  5. One through-line sentence / vocab cards
  6. Border / traps
  7. Writing (Gap, Match, Dictation…)
  8. Cheat sheet at the bottom

Workflow

  1. Read the handout in lessons/, list sections.
  2. Copy a canonical file from html/.
  3. Replace KEY_BASE (unique per lesson), title, nav, theory, VOCAB_BLOCKS / DRILL_SECTIONS / MATCH_SETS.
  4. data-drill / data-match must match object keys.
  5. EN in UI, RU in theory if needed, Check with class btn, flow top to bottom.
  6. Add a card on index.html.
