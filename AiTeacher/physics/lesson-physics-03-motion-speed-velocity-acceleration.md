# Physics Vocabulary Lesson 3

## Topic

Motion, speed, velocity, and acceleration

## Goal

In this lesson, you learn how to speak about movement in physics. These words are essential because many physics topics begin with one simple question: how does an object move?

## Main Rule

In physics, motion is described by changes in position over time.

Basic chain:

`position -> motion -> speed / velocity -> acceleration`

For example:

- `The object changes position.`
- `The object is in motion.`
- `Its speed is 5 meters per second.`
- `Its velocity is 5 meters per second to the east.`
- `Its acceleration increases when the force increases.`

## 1. Motion

### Brief Explanation

`Motion` means a change in position over time.

If an object is in one place at one moment and in another place later, the object is in motion. Motion can be simple, like a ball rolling across a table, or complex, like a drone flying through the air.

In physics, motion is not just "movement" in a casual sense. We describe it carefully using position, time, speed, velocity, and acceleration. This makes motion measurable and predictable.

The opposite idea is `rest`. If an object does not change position relative to a chosen reference point, we say it is `at rest`.

### Examples

1. The motion of the car was recorded by a camera.
2. A falling object is in motion.
3. Physics uses equations to describe motion.
4. The sensor tracks the motion of the robot arm.

## 2. Speed

### Brief Explanation

`Speed` tells us how fast an object moves.

Speed connects distance and time. If an object travels a large distance in a short time, it has high speed. If it travels a small distance in a long time, it has low speed.

Basic formula:

`speed = distance / time`

In English, we read this as:

`speed equals distance divided by time`

Common units of speed are `meters per second` (`m/s`) and `kilometers per hour` (`km/h`). In physics, `meters per second` is very common.

Speed does not tell us direction. If two cars both move at 60 km/h, they have the same speed even if one moves north and the other moves south.

### Examples

1. The speed of the car is 80 kilometers per hour.
2. Speed is distance divided by time.
3. A higher speed means the object covers more distance in the same time.
4. The robot moved at a constant speed.

## 3. Velocity

### Brief Explanation

`Velocity` tells us how fast an object moves and in what direction.

This is the key difference between speed and velocity: speed has no direction, but velocity includes direction. Because of this, velocity is more precise in physics.

For example, `10 m/s` is a speed. But `10 m/s to the east` is a velocity because it includes direction.

Velocity is important when direction matters. In robotics, navigation, aircraft control, satellite motion, and car telemetry, direction is not optional. A system needs to know not only how fast something moves, but also where it is going.

In beginner physics, you can remember this simple rule:

`velocity = speed + direction`

### Examples

1. The velocity of the object is 5 meters per second to the right.
2. Velocity includes both speed and direction.
3. Two objects can have the same speed but different velocities.
4. The drone's velocity changed during the turn.

## 4. Acceleration

### Brief Explanation

`Acceleration` means a change in velocity over time.

Many learners think acceleration only means "getting faster." That is only one case. In physics, acceleration can mean speeding up, slowing down, or changing direction. If velocity changes in any way, acceleration exists.

For example, a car accelerating on a straight road is changing speed. A car turning at constant speed is also accelerating because its direction is changing. This is an important physics idea.

Basic formula:

`acceleration = change in velocity / time`

Common unit:

`meters per second squared` (`m/s^2`)

Acceleration is closely connected to force. Later, you will learn the famous relationship:

`force = mass * acceleration`

### Examples

1. Acceleration describes how quickly velocity changes.
2. The car has positive acceleration when it speeds up.
3. The object has acceleration when it changes direction.
4. Greater force can produce greater acceleration.

## How The Ideas Connect

- `motion` means that position changes over time.
- `speed` tells us how fast the object moves.
- `velocity` tells us speed plus direction.
- `acceleration` tells us how velocity changes.

Simple comparison:

- same speed + different direction -> different velocity
- changing speed -> acceleration
- changing direction -> acceleration

## Useful Language Patterns

These sentence patterns are common in physics English:

1. `The object is in motion.`
2. `The speed of the object is ...`
3. `Velocity includes direction.`
4. `Acceleration is a change in velocity over time.`
5. `The object moves at a constant speed.`
6. `The object accelerates when its velocity changes.`

## Common Confusion

### Speed vs Velocity

`Speed` tells us only how fast something moves. `Velocity` tells us how fast and in what direction.

Examples:

1. `20 m/s` is speed.
2. `20 m/s north` is velocity.
3. Two cars moving at 50 km/h in opposite directions have the same speed but different velocities.

### Acceleration vs Speed

`Speed` describes how fast an object moves now. `Acceleration` describes how quickly velocity changes.

Examples:

1. A car moving at constant speed has no acceleration if its direction does not change.
2. A car speeding up has acceleration.
3. A car slowing down has acceleration.
4. A car turning has acceleration because direction changes.
