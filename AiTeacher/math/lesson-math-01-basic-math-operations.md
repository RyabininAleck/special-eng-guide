# Math Lesson 1

## Basic Math Operations and Symbols

In this lesson, you learn how to name basic math symbols in English and how to read simple expressions aloud. This is important for physics because formulas, calculations, and definitions use mathematical language all the time.

You can describe this topic as `basic math operations`, `math symbols`, `mathematical symbols`, or `how to read equations in English`. The most natural beginner title is `Basic Math Operations and Symbols`.

## Main Symbols

`+` -> `plus`  
Read: `two plus three`  
Example: `2 + 3 = 5` -> `Two plus three equals five.`

`-` -> `minus`  
Read: `seven minus two`  
Example: `7 - 2 = 5` -> `Seven minus two equals five.`

`*` -> `times` or `multiplied by`  
Read: `four times three` / `four multiplied by three`  
Example: `4 * 3 = 12` -> `Four times three equals twelve.`  
Note: in typed text, `*` is often called `asterisk`, but in math we usually read it as `times` or `multiplied by`.

`/` -> `divided by`, sometimes `over` or `per`  
Read: `ten divided by two`  
Example: `10 / 2 = 5` -> `Ten divided by two equals five.`  
Physics example: `m/s` -> `meters per second`

`=` -> `equals` or `is equal to`  
Read: `x equals five` / `density is equal to mass divided by volume`  
Example: `x = 5` -> `X equals five.`

## Useful Physics Reading Patterns

In physics, we often read formulas in a natural spoken way:

1. `v = s / t`
   - `v equals s divided by t`
   - `velocity equals distance divided by time`
2. `d = m / V`
   - `d equals m divided by V`
   - `density equals mass divided by volume`
3. `F = m * a`
   - `F equals m times a`
   - `force equals mass times acceleration`

## Extra Useful Symbols

`(` -> `open parenthesis`  
`)` -> `close parenthesis`  
Example: `(2 + 3) * 4` -> `Open parenthesis two plus three close parenthesis times four.`

`.` -> `point`  
Example: `3.5` -> `three point five`

`%` -> `percent`  
Example: `25%` -> `twenty-five percent`

## Quick Summary

- `+` = `plus`
- `-` = `minus`
- `*` = `times` or `multiplied by`
- `/` = `divided by`
- `=` = `equals`

## Word Forms

`add` -> noun: `addition`, adjective: `additional`  
Example: `Add the two values.`

`subtract` -> noun: `subtraction`, adjective: `subtractive`  
Example: `Subtract 2 from 10.`

`multiply` -> noun: `multiplication`, adjective: `multiplicative`  
Example: `Multiply the mass by the acceleration.`

`divide` -> noun: `division`, adjective: `divisible`  
Example: `Divide the distance by the time.`

`equal` -> noun: `equality`, adjective: `equal`  
Example: `The two sides are equal.`

## Memory Tips

- `plus` -> adding
- `minus` -> taking away
- `times` -> multiplying
- `divided by` -> splitting into parts
- `equals` -> has the same value as
